# ⚡ iOS Style Calculator

A beautiful and modern iOS-inspired calculator built using pure HTML, CSS, and JavaScript.

## ✨ Features

* 📱 iPhone calculator design
* 🌙 Dark mode UI
* ➕ Basic math operations
* 🔄 Positive / Negative toggle
* 💯 Percentage support
* ⚡ Fast and responsive
* 🎨 Clean Apple-style interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📸 Preview

Modern calculator inspired by Apple's iOS calculator app.

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/ios-calculator.git
```

2. Open the project folder

3. Run `index.html`

## 📂 Project Structure

```bash
project/
│
├── index.html

└── script.js
```
